# Security policy

For vulnerabilities, use GitHub's private vulnerability reporting for this repository if enabled. If it is not enabled, contact the maintainer privately through a channel they publish in the repository profile. Do not publish exploit details in a public issue. Avoid including live paste content, credentials, or delete tokens in reports.

The project is pre-1.0. Security fixes target the latest `0.x` release. Public paste URLs are intentionally shareable; do not store secrets unless you accept that anyone with the URL can read them.
